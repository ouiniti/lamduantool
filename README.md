# lamduantool — เครื่องมือคลินิก รพ.ลำดวน

รวมเครื่องมือช่วยงานคลินิกเป็นหน้าเว็บชุดเดียว เปิดจากมือถือหรือแท็บเล็ตได้

| หน้า | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| หน้าแรก | `index.html` | รายการเครื่องมือทั้งหมด |
| ประเมินความปวด | `pain.html` | เลือกเครื่องมือประเมินความปวดให้เหมาะกับผู้ป่วย |
| ประเมินภาวะทุพโภชนาการ → ICD-10 | `malnutrition.html` | BMI / NT / NAF → การวินิจฉัย การรักษา รหัส ICD-10 (E43/E44) ตารางนัดและส่งออก PDF, ICS, CSV |
| ประเมินหัวใจก่อนผ่าตัด | `preop-cardiac.html` | ประเมินตาม AHA/ACC 2026 พร้อมสรุปเป็นภาษาไทย |
| ยาต้านลิ่มเลือดก่อนหัตถการ | `preop-warfarin.html` | แนวทาง warfarin, DOAC และยาต้านเกล็ดเลือด ส่งออก PDF |
| แบบส่งต่อผู้ป่วย | `refer.html` | เลือกโรค กรอกข้อมูล ได้ข้อความส่งต่อตามแม่แบบ คัดลอกไปใช้ |

## วิธีเปิดใช้งาน

1. ดาวน์โหลดหรือ clone โปรเจกต์นี้
2. เปิด `index.html` ด้วยเบราว์เซอร์ (Chrome, Edge, Safari)
3. ต้องมีอินเทอร์เน็ต เพราะไลบรารีและฟอนต์โหลดจาก CDN

ไม่ต้องติดตั้งอะไรเพิ่ม ไม่มี server และไม่มีฐานข้อมูลกลาง

## ข้อมูลและความเป็นส่วนตัว

- ข้อมูลที่กรอกอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ได้ส่งไปที่ไหน
- ตารางนัดในหน้า malnutrition บันทึกไว้ใน localStorage ของเบราว์เซอร์ ถ้าล้างข้อมูลเว็บไซต์ตารางนัดจะหาย
- อย่าใส่ชื่อ-นามสกุลหรือเลข HN ผู้ป่วยในช่องที่ไม่จำเป็น
- repo นี้ควรเก็บเป็น private เพราะอาจมีข้อมูลผู้ป่วยหรือแม่แบบที่ใช้ภายในโรงพยาบาล

## ข้อจำกัด

- เครื่องมือเหล่านี้ช่วยประกอบการตัดสินใจ ไม่แทนดุลยพินิจทางการแพทย์
- ตรวจสอบกับแนวทางเวชปฏิบัติและ formulary ของโรงพยาบาลก่อนใช้งานจริงทุกครั้ง
- แม่แบบในหน้า refer ควรให้แพทย์ทบทวนก่อนใช้ โดยเฉพาะชื่อยาและขนาดยา
